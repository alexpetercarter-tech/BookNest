# 📚 BookNest - Online Bookstore

BookNest is a responsive Online Bookstore web application developed using HTML5, CSS3, and Vanilla JavaScript.

This project is designed for learning:

- Manual Testing
- UI Testing
- Functional Testing
- Compatibility Testing
- Responsive Testing
- Regression Testing
- Smoke Testing
- Deployment

---

# Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

No Backend

No Database

No Frameworks
